## 🔍 So sánh với API Mapping (subcategoryApiMap.js)

### ✅ Danh mục có mapping API (100+ mục)

Tất cả 100+ subcategories trong `subcategoryApiMap.js` đều có:
- Key tương ứng trong `categories.js`
- Endpoint API: `http://localhost:3000/api/products/category/{DisplayName}`
- Được tự động chuyển thành relative path: `/api/products/category/{DisplayName}` để tránh CORS

### ⚠️ Vấn đề tìm thấy (Issues Found)

#### 1. Danh mục sai vị trí (Misplaced Category)
- **Key**: `sua-duong-the-kem-duong-the`
- **Tên**: Sữa dưỡng thể, kem dưỡng thể
- **Vị trí hiện tại**: "Thực phẩm chức năng" → "Hỗ trợ tiêu hóa" ❌
- **Vị trí đúng**: "Dược mỹ phẩm" → "Chăm sóc cơ thể" ✅
- **Giải pháp**: Di chuyển từ `thuc-pham-chuc-nang.categories[4].subcategories[2]` sang `duoc-my-pham.categories[1].subcategories`

#### 2. Menu "Bệnh & Góc sức khỏe" không có API mapping
- 5 danh mục không có subcategories và không có API endpoints:
  - goc-suc-khoe
  - chuyen-trang-ung-thu
  - benh-thuong-gap
  - tin-khuyen-mai
  - truyen-thong
- **Nguyên nhân có thể**: Đây là các trang nội dung tĩnh (CMS), không phải danh mục sản phẩm
- **Hành động**: Cần xác nhận với backend xem có cần API cho các mục này không

#### 3. Trùng lặp key giữa các menu
- **Key**: `cham-soc-da-mat`
  - Xuất hiện trong "Dược mỹ phẩm" (Parent)
  - Xuất hiện trong "Thực phẩm chức năng" → "Hỗ trợ làm đẹp" (Subcategory)
- **Key**: `thuc-pham-do-uong`

  - Xuất hiện trong "Chăm sóc cá nhân" → "Thực phẩm - Đồ uống"
- **Ảnh hưởng**: Có thể gây conflict khi routing hoặc lấy API data
- **Giải pháp**: Đổi tên key để unique (ví dụ: `tptp-cham-soc-da-mat`, `csnn-thuc-pham-do-uong`)
